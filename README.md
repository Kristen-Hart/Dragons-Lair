Rowing Regatta Simulation:

This is a SimPy simulation of a rowing regatta with a specific focus on the events that occur at the start line and on the race course. Code from this simulation is used as examples of how to use SimPy in the guidance document. Written by Kelsey Ritchey.

Dragon’s Lair Simulation:

This is a SimPy simulation of a group of adventurer’s attempting to steal from a dragon’s lair by rolling a 20 sided dice, inspired by the popular game Dungeons and Dragons. Code from this simulation was also used to demonstrate how to use SimPy in the guidance document. Written by Kristen Hart.

Resources:

The resources code was created to demonstrate how one would incorporate resources into their SimPy simulation for the guidance document. Due to neither the Rowing Regatta nor the Dragon’s Lair containing resources, a supplemental simple simulation was created to showcase resources for the guide. Written by Kristen Hart.
